A small tool for the moment a number is called

One call.
Two destinations.
Everyone stays in sync.

CareCall Appointment Notifier gives staff a simple way to call a number and send it to the right screen: a public display or the reception desk. The receiving screen shows the number, says it aloud, and starts an elapsed-time counter.

Explore the repository Read the README

What the project does

This is the calling layer around an appointment or queue. It moves a short announcement from staff to the screen that needs it.

01

Staff choose a destination

The Doctor screen has separate Display and Reception tabs. Each tab has its own keypad and selected number.

02

The server routes the call

The number is sent to one logical channel. Connected screens in the other channel do not receive it.

03

The screen announces it

The selected screen updates immediately, speaks through the browser, and shows how long ago the number arrived.

A direct path through the app

The browser pages and live-message endpoint share one Node.js server and one configured port.

Doctor screen

Plain browser JavaScript sends a small JSON message with the number and its target channel.

→
Node.js server

Built-in HTTP serves the pages. The ws library carries live messages and routes them in memory.

→
Display or Reception

The matching channel receives the call. Browser speech synthesis provides the voice announcement.

V3 narrows the flow to one display

V1 and V2 keep the earlier screens. V3 removes Reception and focuses on one Doctor console and one external Display. The Doctor console has a Call tab and a Display preview tab; the preview mirrors the same number and elapsed time shown outside.

What it is built with

Small, understandable pieces that fit the job.

Node.js built-in HTTPServes the HTML, CSS, and JavaScript and accepts the WebSocket upgrade. There is no Express.
wsThe app's only runtime dependency. It keeps a live connection open for real-time announcements.
Browser-native UIPlain HTML, CSS, and JavaScript; speech comes from the browser's speech synthesis.
In-memory channelsNo database or saved call history. Connected screens are tracked only while the server is running.

A notifier, not a booking system

The app calls numbers and displays them. It does not create appointments, store patient records, or manage a calendar. The role in a WebSocket URL selects a screen channel; it is not a login. Keep the running app on a trusted local network until authentication and TLS are added.
