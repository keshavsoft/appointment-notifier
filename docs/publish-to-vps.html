Step-by-Step Production Runbook

How to Publish appointment-notifier to Your VPS

Follow these exact steps while connected to your VPS terminal (root@server6358:/etc/caddy#). This runbook uses the entire KeshavSoft Caddy toolkit to inspect open ports, generate the route block, safely insert it into /etc/caddy/caddy.json, and launch the service with zero downtime.

The KeshavSoft Caddy Suite In Action
1. caddy-cli Inspects running routes and occupied ports on the server.
2. caddy-template Generates the validated Caddy JSON route block for port 3000.
3. caddy-template-knowledge Explains why single-port proxy handles both HTTP and WebSockets.
4. caddy-hosting The overarching ecosystem hub and architecture dashboard.
1

Inspect Occupied Ports on the VPS

On your VPS terminal, navigate to /etc/caddy and run our caddy-cli tool:

SSH: root@server6358:/etc/caddy# 
root@server6358:/etc/caddy# npx caddy-cli -p
Confirmed on Your Server:
Your VPS currently occupies ports 3001, 3025, 8080, 9010, 9011, 9012, and 9328.
👉 Port 3000 is completely unallocated and ready for use!
2

Generate the Route JSON Block with caddy-template

Use caddy-template to generate the unified reverse proxy route block for appointment.keshavsoft.com on port 3000, and save it to a temporary file:

SSH: root@server6358:/etc/caddy# 
root@server6358:/etc/caddy# npx caddy-template proxy appointment.keshavsoft.com 3000 > /tmp/appointment-route.json

You can verify the generated file by running cat /tmp/appointment-route.json:

/tmp/appointment-route.json
{
  "match": [
    {
      "host": [
        "appointment.keshavsoft.com"
      ]
    }
  ],
  "handle": [
    {
      "handler": "subroute",
      "routes": [
        {
          "handle": [
            {
              "handler": "reverse_proxy",
              "upstreams": [
                {
                  "dial": "localhost:3000"
                }
              ]
            }
          ]
        }
      ]
    }
  ],
  "terminal": true
}
3

Insert the Route into /etc/caddy/caddy.json

To avoid syntax errors, missing commas, or misplaced braces when manually editing JSON files, use this foolproof Node.js one-liner directly on your VPS. It automatically creates a timestamped backup, appends the new route, and writes it back cleanly:

SSH: Safe Automated Append (Recommended) 
node -e '
const fs = require("fs");
const caddyFile = "/etc/caddy/caddy.json";
const routeFile = "/tmp/appointment-route.json";

const config = JSON.parse(fs.readFileSync(caddyFile, "utf8"));
const route = JSON.parse(fs.readFileSync(routeFile, "utf8"));

// 1. Create a safe backup first
const backupFile = caddyFile + ".bak." + Date.now();
fs.writeFileSync(backupFile, JSON.stringify(config, null, 2));
console.log("Backup created at:", backupFile);

// 2. Append route to apps.http.servers.srv0.routes
config.apps.http.servers.srv0.routes.push(route);

// 3. Write back updated config
fs.writeFileSync(caddyFile, JSON.stringify(config, null, 2));
console.log("Successfully appended appointment.keshavsoft.com to " + caddyFile + "!");
'
Alternative (Manual Editing with nano):
If you prefer manual editing:
  1. Run: cp /etc/caddy/caddy.json /etc/caddy/caddy.json.bak
  2. Run: nano /etc/caddy/caddy.json
  3. Scroll to the end of apps.http.servers.srv0.routes (after the cc9.keshavsoft.com block).
  4. Add a comma , after the previous route object, and paste the contents of /tmp/appointment-route.json before the closing bracket ].
4

Reload Caddy & Verify with caddy-cli

Reload Caddy configuration without dropping any active connections:

SSH: root@server6358:/etc/caddy# 
root@server6358:/etc/caddy# caddy reload --config /etc/caddy/caddy.json

Now verify that our new route is active by running caddy-cli:

SSH: root@server6358:/etc/caddy# 
root@server6358:/etc/caddy# npx caddy-cli
Expected Output:
You will see row 10: 'appointment.keshavsoft.com' mapped to 'localhost:3000'!
5

Clone & Start appointment-notifier with PM2

Now clone the app repository and launch it on port 3000:

SSH: Terminal Commands 
# 1. Create and enter web directory
mkdir -p /var/www
cd /var/www

# 2. Clone repository from GitHub
git clone https://github.com/keshavsoft/appointment-notifier.git
cd appointment-notifier

# 3. Install dependencies
npm install --production

# 4. Start service with PM2 on port 3000
PORT=3000 pm2 start app.js --name appointment-notifier
pm2 save
